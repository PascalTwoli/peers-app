# Peers Marketing Website

This package contains the Next.js + TailwindCSS marketing site for Peers.

## Run

From workspace root:

```bash
npm install
npm run dev -w @peers/marketing
```

## Build

```bash
npm run build -w @peers/marketing
npm run start -w @peers/marketing
```

## Screenshot Slots

Place your real screenshots in `public/screenshots/` using these names:

- `room-call-desktop.png`
- `room-call-mobile.png`
- `audio-call-desktop.png`
- `chat-desktop.png`
- `chat-mobile.png`
- `peers-mobile.png`

If these files are not present, the cards still render as styled placeholders.
